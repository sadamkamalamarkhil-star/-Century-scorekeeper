Moving from the GitHub site
  1. On your phone, open this backup page on the original GitHub site, using the same browser or installed app that holds your games. Export the backup there.
  2. Send the downloaded JSON file to your destination device, or keep it in Files on your phone.
  3. Open this page on the new CueScore site, choose the file, review it, then restore.

Browsers keep data separately for each site origin and browser profile. A destination browser cannot read your phone’s localStorage. This is a manual transfer, not live club sync. This page does not upload existing histories or any backup contents anywhere.

Backups contain player names, scores and club receipts. Keep them private. Only data still stored in this browser can be exported; previously deleted records cannot be recovered.

Before you restore

Restore replaces all CueScore data currently saved on this device for this site, including unfinished games and history. It does not merge histories. Close other CueScore tabs first.

A safety backup of this browser’s current data downloads automatically before any changes. Allow the download and keep that file. Existing unrelated browser storage is preserved.

A running club timer keeps its original start time, so time away still counts. Pause it on the source device before export if needed. After restore, opening the scorekeeper may apply its usual migrations and history limits.
